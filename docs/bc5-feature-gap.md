# DiffStudio 与 Beyond Compare 5 的功能差距（第二轮复核）

对比基准：`C:\Program Files\Beyond Compare 5`（`BCompare.exe`，含 1036 条命令级字符串，
`BCompare.chm` 约 240 个帮助主题）。
对比对象：本仓库当前工作区（0.1.0 + P0 新增能力）。

复核方法：对 `src/`、`main.js`、`preload.js` 做关键词扫描，并对每一条命中的人工甄别
（排除变量名、注释、UI 容器 id 造成的误报），扫描时点为 P0 合并之后。

## 一、P0 复核结论：四项均已实现

| 能力 | 证据 | 复核 |
| --- | --- | --- |
| 压缩包当文件夹比较 | `core/archive.js`：`readArchive` / `parseZip` / `parseTar` / `inflateGzip` | ✅ zip / tar / tgz / gz 实测解析解压正确 |
| 文件夹三路合并 | `views/folderMerge.js` + `core/folderMerge.js`：`planThreeWay` | ✅ 执行与撤销实测通过，冲突不被自动覆盖 |
| 文件操作补全 | `main.js`：`fs:rename` / `fs:move` / `fs:touch`；`core/fileOps.js` | ✅ API 与真实点击均实测 |
| 查找文件内文本 | `core/search.js`：`searchFiles` | ✅ 真实点击命中渲染 |

P0 剩余的小口子（不构成"功能缺失"，属于打磨项）：

- 压缩包仅覆盖 zip / tar / tgz / gz；**rar、7z、xz、bz2 未支持**（扫描 `\.rar`、`7z` 命中 0）。
- 压缩包内文件的双击打开仍走临时目录路径，未做虚拟文件系统的原位查看。
- 查找目前固定为"普通文本 + 大小写不敏感"，正则 / 全字匹配 / 区分大小写在 UI 上未暴露
  （`core/search.js` 的 `regex`、`wholeWord`、`caseSensitive` 选项已实现但未接线）。

## 五、结论

- **功能缺口没有消失，只是 P0 四类被补齐**。真正拉大差距的是 **规则/格式体系（#1–#6）**
  与 **远程/自动化（#10–#11）**，这两块属于架构级投入，不是零散功能。
- P1 第一项「重要/不重要规则」已完成（`core/unimportant.js`），规则体系已经开了口子：
  后续的替换规则、表格列规则可以复用同一套"正则 + 后处理"模式。
- 下一步建议：**替换规则（#2）→ 表格列规则（#5）→ 语法高亮（#4）**。
