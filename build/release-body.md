## DiffStudio 0.1.1

第二个公开版本：在 0.1.0 的基础上补齐了与 Beyond Compare 5 的主要功能差距，
新增四种比较能力、文件夹批量操作与查找、以及四类比较规则。

### 新增功能

- **压缩包按文件夹比较**：zip / tar / tgz / gz 任一侧可直接作为文件夹树比较。
  无需第三方解压库；条目路径已归一化，`..` 与绝对路径无法逃出临时目录（zip-slip 防护）。
- **三方文件夹合并**：新会话类型，按 基准 / 左 / 右 三方分类，单侧改动自动合并，
  冲突永不自动解决；可应用到任意一侧，每步可撤销并保留备份。
- **文件操作**：文件夹比较中支持重命名、新建文件夹、改时间戳、移动到对侧。
  落盘前校验非法字符、保留名、重名、结尾点/空格，且任何操作都不会覆盖已有项目。
- **在文件中查找**：跨左右两个文件夹的全文检索，按文件分组展示结果；
  支持正则、全字匹配、区分大小写，非法正则给出提示而不是静默返回空。
- **不重要文件筛选**：用相对路径正则隐藏匹配项，不改变比较结果；
  规则写错时只告警并暂停筛选，不会让整棵树消失。
- **语法高亮**：文本比较支持 JS/TS、Python、Java、C/C++、JSON、XML/HTML、SQL、Shell。
  按左侧文件扩展名自动识别并可手动覆盖；token 颜色与行内差异底纹可以共存。
- **表格列规则**：CSV 每列可单独设置 `ignore`（忽略）、`case`（忽略大小写）、
  `trim`、`numeric`（`1.0` 等于 `1`）、`regex:<pattern>`（只比较匹配部分，
  例如只比较时间戳里的日期）。列可用表头名或 `#序号` 选择，`*` 表示全部列。
- **替换规则**：文本比较接受 `/正则/=>替换` 规则，在比较**之前**改写文本，
  所以时间戳、版本号、构建号的差异会被忽略。文件不会被修改，界面显示的仍是原文。
- **重要 / 不重要规则**：按正则把仅由匹配文本造成的差异降级为「不重要」（灰色而非黄色），
  不计入差异导航并单独计数，适合配合「只看重要差异」使用。

### 安装

下载下方 `DiffStudio-Setup-0.1.1.exe` 运行即可，仅支持 Windows x64。
默认安装到当前用户目录，可自选安装路径，创建桌面与开始菜单快捷方式。

### 已知限制

- 压缩包仅支持 zip / tar / tgz / gz，不支持 rar / 7z / xz / bz2。
- 表格比较仅支持 CSV。
- 「只看重要差异」是淡化显示，不是隐藏行。
- 会话类型共 9 种，尚缺注册表比较、媒体比较、版本比较。- 安装包未做代码签名，首次运行可能出现 SmartScreen 提示。
- 暂无 macOS / Linux 构建。
